# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Report it privately through the repository's Security tab ("Report a vulnerability"). Include what you found, how to reproduce it, and the impact you expect. You will get a reply before any details are made public.

## Supported versions

Only the latest 0.x release receives security fixes.

| Version | Supported |
|---|---|
| Latest 0.x release | Yes |
| Older releases | No |
